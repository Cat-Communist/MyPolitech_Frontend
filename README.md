# Путешествие по Политеху

Главное меню игры-путешествия по истории ИРНИТУ: экран загрузки, выбор режима
(«Для выпускников» / «Для поступающих»), заглушки режимов и окно «Об игре».

Чистые HTML, CSS и JavaScript — без сборки, зависимостей и обращений в сеть.

## Как запустить

Откройте `index.html` двойным щелчком. Всё работает по протоколу `file://`:
внешних запросов нет, шрифты и картинки лежат рядом, интернет не нужен.

Если понадобится отдать страницу по сети, подойдёт любой статический сервер:

```
python -m http.server 8000
```

и затем `http://localhost:8000` в браузере.

## Структура

```
index.html            разметка; экраны лежат в <template>
css/fonts.css         подключение локальных шрифтов (@font-face)
css/variables.css     цвета, шрифты, метрики сцены
css/base.css          сброс и анимации (@keyframes)
css/menu.css          сцена, фон и все экраны
js/config.js          тексты, пути к картинкам, тайминг загрузки
js/screens.js         фон, метрики сцены, переключение экранов
js/main.js            загрузка, звук, обработка событий
assets/img/           логотипы
assets/fonts/         Montserrat и JetBrains Mono (woff2)
```

## Где что менять

### Тексты

Все надписи собраны в `js/config.js`, объект `texts`. В разметке текста нет:
элементы помечены атрибутом `data-text`, значение подставляется по ключу.

```js
texts: {
  title: 'Путешествие по Политеху',
  tagline: 'Игра-путешествие по истории университета',
  alumniTitle: 'Для выпускников',
  ...
}
```

Достаточно исправить строку. Ключи трогать не нужно — на них ссылается
разметка.

Там же лежит `loaderMs` — сколько миллисекунд идёт полоса загрузки.

### Цвета и шрифты

`css/variables.css`, блок `:root`. Остальные стили цветов не содержат, только
ссылаются на переменные, поэтому правка здесь меняет оформление целиком.

| Переменная                              | За что отвечает                   |
|-----------------------------------------|-----------------------------------|
| `--c-page`                              | фон вокруг сцены                  |
| `--c-bg`                                | фон самой сцены                   |
| `--c-surface`                           | карточки, кнопки, окно «Об игре»  |
| `--c-ink` / `--c-ink-dim`               | основной и второстепенный текст   |
| `--c-line`                              | рамки и разделители               |
| `--c-blue` / `--c-blue-deep`            | акцент и акцент при нажатии       |
| `--c-teal`                              | левый край градиента заголовка    |
| `--g-title`                             | сам градиент заголовка            |
| `--c-grid` / `--c-circuit` / `--c-code` | сетка, дорожки и столбцы на фоне  |
| `--font-ui` / `--font-mono`             | шрифты                            |

Ниже в том же файле — метрики сцены (`--mode-w`, `--title-size`, `--menu-gap`
и другие). Значения в `:root` действуют для альбомной ориентации; для
портретной их переопределяет `applyLayout` в `js/screens.js`.

Шрифты лежат в `assets/fonts/` и подключаются в `css/fonts.css`. Чтобы
заменить шрифт, положите туда woff2, опишите `@font-face` и поменяйте
`--font-ui` или `--font-mono`.

### Картинки

Файлы — в `assets/img/`, пути к ним — в `js/config.js`:

```js
images: {
  mark: 'assets/img/ipolytech.svg',
  logo: 'assets/img/logo-irnitu.png',
}
```

Положите новый файл в `assets/img/` и поправьте путь. В разметке пути не
дублируются: у тегов `<img>` стоит `data-img`, источник подставляется из
конфига.
