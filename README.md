# Путешествие по Политеху

Главное меню игры-путешествия по истории ИРНИТУ: экран загрузки, выбор режима
(«Для выпускников» / «Для поступающих»), заглушки режимов и окно «Об игре».

Чистые HTML, CSS и JavaScript — без сборки, зависимостей и обращений в сеть.

## Как запустить

Откройте `index.html` двойным щелчком. Всё работает по протоколу `file://`:
внешних запросов нет, шрифты и картинки лежат рядом, интернет не нужен.

Если понадобится отдать страницу по сети, подойдёт любой статический сервер,
например:

```
python -m http.server 8000
```

и затем `http://localhost:8000` в браузере.

## Структура

```
index.html            разметка; экраны лежат в <template>
css/fonts.css         подключение локальных шрифтов (@font-face)
css/variables.css     цвета, шрифты, метрики сцены
css/base.css          сброс и анимации (@keyframes)
css/menu.css          сцена, фон и все экраны
js/config.js          тексты, пути к картинкам, тайминг загрузки
js/screens.js         фон, метрики сцены, переключение экранов
js/main.js            загрузка, звук, обработка событий
assets/img/           логотипы
assets/fonts/         Montserrat и JetBrains Mono (woff2)
```

## Где что менять

### Тексты

Все надписи собраны в одном месте — `js/config.js`, объект `texts`. В разметке
текста нет: элементы помечены атрибутом `data-text`, и значение подставляется
по ключу.

```js
texts: {
  title: 'Путешествие по Политеху',
  tagline: 'Игра-путешествие по истории университета',
  alumniTitle: 'Для выпускников',
  ...
}
```

Чтобы поменять надпись, достаточно исправить строку. Ключи трогать не нужно —
на них ссылается разметка.

Там же лежит `loaderMs` — сколько миллисекунд идёт полоса загрузки.

### Цвета и шрифты

`css/variables.css`, блок `:root`. Остальные стили цветов не содержат, только
ссылаются на переменные, поэтому правка здесь меняет оформление целиком.

| Переменная                     | За что отвечает                        |
|--------------------------------|----------------------------------------|
| `--c-page`                     | фон вокруг сцены                       |
| `--c-bg`                       | фон самой сцены                        |
| `--c-surface`                  | карточки, кнопки, окно «Об игре»       |
| `--c-ink` / `--c-ink-dim`      | основной и второстепенный текст        |
| `--c-line`                     | рамки и разделители                    |
| `--c-blue` / `--c-blue-deep`   | акцент и акцент при нажатии            |
| `--c-teal`                     | левый край градиента заголовка         |
| `--g-title`                    | сам градиент заголовка                 |
| `--c-grid` / `--c-circuit` / `--c-code` | элементы фона                 |
| `--font-ui` / `--font-mono`    | шрифты                                 |

Ниже в том же файле — метрики сцены (`--mode-w`, `--title-size`, `--menu-gap`
и другие). Значения в `:root` действуют для альбомной ориентации; для
портретной их переопределяет функция `applyLayout` в `js/screens.js`.

### Картинки

Файлы — в `assets/img/`, пути к ним — в `js/config.js`:

```js
images: {
  mark: 'assets/img/ipolytech.svg',
  logo: 'assets/img/logo-irnitu.png',
}
```

Чтобы заменить логотип, положите новый файл в `assets/img/` и поправьте путь.
В разметке пути не дублируются: у тегов `<img>` стоит `data-img`, источник
подставляется из конфига.

### Шрифты

Montserrat и JetBrains Mono лежат в `assets/fonts/` в формате woff2 и
подключаются в `css/fonts.css`. Оба семейства вариативные: один файл на
поднабор символов покрывает все насыщенности, поэтому `font-weight` задан
диапазоном. Сохранён `unicode-range`, так что браузер загружает только нужные
диапазоны — кириллицу и латиницу.

Чтобы заменить шрифт, положите woff2 в `assets/fonts/`, опишите `@font-face`
в `css/fonts.css` и поменяйте `--font-ui` или `--font-mono`
в `css/variables.css`.

## Как всё устроено

**Сцена.** Вся вёрстка живёт внутри прямоугольника фиксированного размера —
1600×900 в альбомной ориентации и 900×1600 в портретной. Он целиком
масштабируется под окно через `transform: scale(...)`, поэтому пропорции не
меняются ни на каком экране. Размер и масштаб считает `applyLayout`
в `js/screens.js`.

**Экраны.** Каждый экран описан в `index.html` внутри `<template>`. При
переходе прежний экран удаляется из DOM, а новый клонируется из шаблона —
благодаря этому анимация появления проигрывается заново при каждом входе.
Переключение — функция `show` в `js/screens.js`.

**Фон.** Сетка, схемные дорожки и падающие столбцы из нулей и единиц строятся
кодом в `buildBackground` (`js/screens.js`). Используется генератор
псевдослучайных чисел с фиксированным зерном `seed = 11`, поэтому картина
всегда одна и та же. Если поменять зерно, изменится расположение и содержимое
столбцов.

**Звук.** Отдельных звуковых файлов нет: короткие сигналы синтезируются
осциллятором Web Audio в функции `blip` (`js/main.js`). По умолчанию звук
выключен; включается кнопкой в правом верхнем углу.

**Управление с клавиатуры.** `Escape` закрывает окно «Об игре», а на экране
заглушки возвращает в меню.

## Добавить новый экран

1. Опишите разметку в `index.html` внутри `<template id="tpl-имя">`.
2. Тексты добавьте в `texts` (`js/config.js`), в разметке проставьте
   `data-text` с соответствующими ключами.
3. Стили — в `css/menu.css`; корневому элементу нужны `position: absolute`
   и `inset: 0`.
4. Показывайте экран вызовом `Screens.show('имя')`.
5. Обработчик нажатия добавьте в делегирующий слушатель `click`
   в `js/main.js` — отдельные экраны монтируются и удаляются, поэтому вешать
   обработчики на конкретные кнопки нельзя.

## Доступность

Учитывается системная настройка «уменьшить движение»: при
`prefers-reduced-motion: reduce` все анимации и переходы отключаются
(`css/base.css`).
