# Путешествие по Политеху

Игра-путешествие по истории ИРНИТУ. Экран загрузки и главное меню с тремя
разделами:

- **Галерея выпускников** — шкала лет и фотоальбом с перелистыванием, по клику
  фото открывается крупно;
- **История** — схема институтов и направлений, по каждому направлению
  страница с историей;
- **Мини-игры** — пока заглушка «Скоро».

И окно «Об игре».

Чистые HTML, CSS и JavaScript — без сборки, зависимостей и обращений в сеть.

## Как запустить

Откройте `index.html` двойным щелчком. Всё работает по протоколу `file://`:
внешних запросов нет, шрифты и картинки лежат рядом, интернет не нужен.

Если понадобится отдать страницу по сети, подойдёт любой статический сервер:

```
python -m http.server 8000
```

и затем `http://localhost:8000` в браузере.

## Структура

```
index.html            разметка; экраны лежат в <template>
css/fonts.css         подключение локальных шрифтов (@font-face)
css/variables.css     цвета, шрифты, метрики сцены
css/base.css          сброс и анимации (@keyframes)
css/menu.css          сцена, фон, меню, заглушка, «Об игре»; общие шапка и кнопки разделов
css/gallery.css       галерея: шкала лет, альбом, просмотр фото
css/history.css       история: схема, панель института, страница направления
js/config.js          тексты, пути к картинкам, тайминг загрузки
js/data/gallery.js    данные галереи: годы и фото
js/data/history.js    данные истории: институты и направления
js/screens.js         фон, метрики сцены, переключение экранов
js/gallery.js         логика галереи
js/history.js         логика истории
js/main.js            загрузка, звук, обработка событий, вход в разделы
assets/img/           логотипы
assets/fonts/         Montserrat и JetBrains Mono (woff2)
```

## Где что менять

### Тексты

Все надписи собраны в `js/config.js`, объект `texts`. В разметке текста нет:
элементы помечены атрибутом `data-text`, значение подставляется по ключу.

```js
texts: {
  title: 'Путешествие по Политеху',
  tagline: 'Игра-путешествие по истории университета',
  galleryTitle: 'Галерея выпускников',
  ...
}
```

Достаточно исправить строку. Ключи трогать не нужно — на них ссылается
разметка.

Там же лежит `loaderMs` — сколько миллисекунд идёт полоса загрузки.

### Цвета и шрифты

`css/variables.css`, блок `:root`. Остальные стили цветов не содержат, только
ссылаются на переменные, поэтому правка здесь меняет оформление целиком.

| Переменная                              | За что отвечает                   |
|-----------------------------------------|-----------------------------------|
| `--c-page`                              | фон вокруг сцены                  |
| `--c-bg`                                | фон самой сцены                   |
| `--c-surface`                           | карточки, кнопки, окно «Об игре»  |
| `--c-ink` / `--c-ink-dim`               | основной и второстепенный текст   |
| `--c-line`                              | рамки и разделители               |
| `--c-blue` / `--c-blue-deep`            | акцент и акцент при нажатии       |
| `--c-teal`                              | левый край градиента заголовка    |
| `--g-title`                             | сам градиент заголовка            |
| `--c-grid` / `--c-circuit` / `--c-code` | сетка, дорожки и столбцы на фоне  |
| `--c-photo` / `--c-photo-ink`           | серая заглушка вместо фото        |
| `--font-ui` / `--font-mono`             | шрифты                            |

Ниже в том же файле — метрики сцены (`--mode-w`, `--title-size`, `--menu-gap`
и другие). Значения в `:root` действуют для альбомной ориентации; для
портретной их переопределяет `applyLayout` в `js/screens.js`. Галерея и
история свёрстаны только под альбомную сцену: в вертикальном окне она просто
уменьшается.

Шрифты лежат в `assets/fonts/` и подключаются в `css/fonts.css`. Чтобы
заменить шрифт, положите туда woff2, опишите `@font-face` и поменяйте
`--font-ui` или `--font-mono`.

### Картинки

Файлы — в `assets/img/`, пути к ним — в `js/config.js`:

```js
images: {
  mark: 'assets/img/ipolytech.svg',
  logo: 'assets/img/logo-irnitu.png',
}
```

Положите новый файл в `assets/img/` и поправьте путь. В разметке пути не
дублируются: у тегов `<img>` стоит `data-img`, источник подставляется из
конфига.

## Данные галереи и истории

Фото, подписи, институты и направления лежат отдельно от кода, в папке
`js/data/`. Это обычные `.js`-файлы, а не `.json`: браузер не даёт прочитать
JSON по `file://`, а скрипт подключается без ограничений.

Шкала лет, страницы альбома, узлы схемы и дорожки к ним в коде не прописаны —
всё считается из этих файлов. Достаточно поправить данные и обновить страницу.

Пара правил, чтобы файл не сломался:

- каждая запись — в фигурных скобках, после каждой записи запятая;
- строки — в одинарных кавычках `'…'`. Если в тексте нужен апостроф,
  поставьте перед ним обратную косую черту: `'Д\'Артаньян'`. Обычные
  русские кавычки «ёлочки» можно писать как есть;
- пути к фото — от `index.html`, через `/`, например
  `'assets/gallery/1960/01.jpg'`. Пустой путь `''` — вместо фото серая
  заглушка.

Если после правки страница перестала открываться дальше загрузки, скорее
всего, пропущена запятая или кавычка. Ошибку с номером строки покажет консоль
браузера (F12 → Console).

### Галерея — `js/data/gallery.js`

```js
window.GALLERY_DATA = [
  {
    year: 1960,
    photos: [
      { src: 'assets/gallery/1960/01.jpg', caption: 'Общее фото выпуска', institute: 'Название института' },
      { src: '', caption: 'Подпись к фотографии', institute: 'Название института' },
    ],
  },
  ...
];
```

**Добавить год.** Скопируйте блок `{ year: …, photos: [ … ] },` целиком и
поменяйте год. Порядок в файле не важен: шкала сортирует годы сама. На
шкале одновременно видно девять лет, остальные открываются стрелками.

**Добавить фото.** Положите файл, например, в `assets/gallery/1960/` и
добавьте строку в `photos` нужного года:

```js
{ src: 'assets/gallery/1960/05.jpg', caption: 'Кто на снимке, где и когда', institute: 'Название института' },
```

Фото идут в альбоме в том порядке, в каком записаны. Первое фото года
попадает на титульную страницу выпуска, остальные — по три на страницу.
Число страниц и разворотов, счётчики «N фотографий» и миниатюры в просмотре
пересчитываются сами. Подпись и институт показываются при просмотре фото
крупно.

### История — `js/data/history.js`

```js
window.HISTORY_DATA = {
  core: { name: 'Политех', year: 1930 },

  institutes: [
    {
      name: 'Название института',
      short: 'ИИТиАД',
      about: 'Краткая история института.',
      directions: [
        {
          name: 'Название направления',
          history: [
            'Первый абзац истории.',
            'Второй абзац.',
          ],
          stages: [
            { year: 1960, text: 'Описание этапа' },
          ],
          photo: { src: 'assets/history/direction.jpg', caption: 'Подпись к фото' },
        },
      ],
    },
    ...
  ],
};
```

- `core` — надпись и год на центральном чипе схемы.
- `name` — полное название института: в боковой панели и над названием
  направления на его странице.
- `short` — короткая подпись на узле схемы. Узел узкий, длинное название в
  него не влезет; если оставить `''`, на узле будет «Институт 01» и т. д.
- `about` — краткая история института в боковой панели.
- `history` — абзацы истории направления, по строке на абзац. Первый абзац
  выводится основным цветом, остальные — приглушённым.
- `stages` — ключевые этапы, сколько угодно.
- `photo` — фото или иллюстрация справа на странице направления.

**Добавить направление.** Скопируйте блок одного направления (от `{` до
`},`) внутрь `directions` нужного института и поменяйте тексты. Под узлом
института появится ещё один «пин», в боковой панели — ещё одна строка, а
кнопки «Предыдущее» / «Следующее направление» начнут проходить и через него.
Номера вида `01.03` считаются по порядку в файле.

**Добавить институт.** Скопируйте блок института целиком (от `{` с `name`
до `},` после его `directions`) внутрь `institutes`. Узлы на схеме
перестроятся по эллипсу сами: первый институт в списке — сверху, дальше по
часовой стрелке. Схема рассчитана примерно на восемь институтов; при большем
числе узлы начнут наезжать друг на друга.
